# Third-party source acknowledgements

The supplied implementation adapts research code. Local renaming does not change the origin of reused components.

- AlphaPre (K. Lin et al., CVPR 2025): complex amplitude/phase modeling and parts of the original experiment pipeline. [Paper](https://openaccess.thecvf.com/content/CVPR2025/html/Lin_AlphaPre_Amplitude-Phase_Disentanglement_Model_for_Precipitation_Nowcasting_CVPR_2025_paper.html).
- DiffCast: dataset/evaluation conventions referenced by the supplied code. [Repository](https://github.com/DeminYu98/DiffCast).
- OpenSTL: source acknowledged by the original repository. Unused local baseline packages were removed; attribution remains. [Repository](https://github.com/chengtan9907/OpenSTL).
- PFGNet (X. Cai et al., 2026): peripheral/context building blocks and the matching GRN/depthwise layer dependency supplied by the author.
- SEVIR: the loader records its source as https://github.com/MIT-AI-Accelerator/neurips-2020-sevir and retains its MIT license attribution.

Source attribution is preserved. This cleanup does not select a new license for the author's full project.
